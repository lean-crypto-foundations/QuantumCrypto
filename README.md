# QuantumCrypto

The quantum random-oracle toolkit for cryptographic proofs in Lean 4, on Mathlib and
[QuantumFoundations](https://github.com/lean-crypto-foundations/QuantumFoundations):
one-way to hiding, the semi-classical oracle, multi-round adversaries, the compressed
oracle, measure-and-reprogram, k-wise independent oracles, and search bounds.
Lean v4.35.0, Mathlib v4.35.0.
